# lanrdp — Windows 局域网远程桌面

DXGI 抓屏 + H.264 压缩 + 裸 TCP 传输的 Windows 远程桌面，Qt 6 / C++ / Win32 编写。
为**局域网**设计：低延迟、零外部服务依赖、绿色免安装。

## 功能

- **一个程序双角色**：既能当控制端连接别人，也能开监听被别人连接，可同时进行
- **多路观看**：一台控制端最多同屏连 4 台被控端（自动 2×2 网格，可单格占满）
- **多控一**：一台被控端最多接受 4 个控制端同时接入观看
- **多屏切换**：被控端有 2 块以上显示器时，悬浮条上可切换看哪一块（同一时刻只传一块）
- **操作权令牌**：同一时刻只有一个控制端能操作鼠标键盘；可申请、让出、被控端可随时收回
- **H.264 压缩**（Media Foundation 编码），也可关闭走原始帧
- **文件双向传输**（两个方向都能发，接收方自选目录，单文件上限 4 GiB）：
  - 控制端 → 被控端：往画面里拖放即传；也可在别处复制文件后，点那一格悬浮条上的【发送文件】直传
    （**复制本身不发送**，点了才发，一次最多 64 个），按钮右侧小三角是【选择文件…】
  - 被控端 → 控制端：在远程画面里 Ctrl+C 复制一批文件，回到本机 Ctrl+V 即得；
    也可用【被控 → 发送文件…】自己挑文件，发给正在操作本机的那一端（没人在操作时不可用）
- **剪贴板双向同步**：文本与文件；图片和 HTML 不同步
- **局域网自动发现**：【新连接…】顶部列出正在等人连接的机器，点一行即填好地址与端口
  （同一台机器接了两条网线时会一行一条，点哪行就连哪条；发现不到也能手打地址）
- **声音**：控制端可听被控端的系统声音（只下行；在【设置…】里可关）
- **一键隐私遮挡**（`Ctrl+Alt+F11`，切到别的程序也生效）：本机所有屏幕立即变黑，同时
  **停止发送画面与声音、收回操作权** —— 对方看到的是定格画面，点不动也听不到；
  再按一次恢复，画面立刻清晰。（被控端菜单里也有【隐私遮挡 / 取消遮挡】）
- **全局急停**（`Ctrl+Alt+F12`，切到别的程序也生效）：一下停止监听并断开全部控制端，
  之后对方再连也连不上
- **断线自动重连**（带退避，默认开启）+ 心跳判死
- **自适应码率**：随网络状况调整；上限可在【开始监听…】里选（4 / 8 / 12 / 16 Mbps，默认 8）
- **托盘常驻**（可选，默认关）：最小化或关闭窗口后收进通知区域，共享继续进行
- **单实例保护**（可选，默认关）：重复启动不再开出第二个窗口，只把已有窗口叫到前台
- **六项开关集中在【设置…】**：断线自动重连 / 接收对方声音 / 最小化到托盘 /
  同时只开一个窗口 / 开机后自动开始等待连接 / 键鼠控制；
  除「键鼠控制」（每次启动重新同意）外都会记住
- **状态栏看质量**：鼠标停在状态栏上，显示往返时间、解码耗时，并给一句话判断
  （如「网络延迟偏高」「本机解码吃紧」）
- **界面中英文切换**：【设置 → 语言】可选「中文 / English / 跟随系统」，切换即时生效（不用重启）
- **深色 / 浅色主题**：【设置 → 外观】切换，即时生效并记住
- 可用 `windeployqt` 打包成不依赖目标机安装 Qt 的绿色目录

## 使用

### 被控端

1. 启动 `lanrdp.exe` → 菜单【被控 → 开始监听…】（`Ctrl+1`）
2. 填端口（如 `9000`）、口令（至少 6 位、不含空格，仅英文数字符号）→ 确定
3. 懒得口头报参数就点【复制邀请串】：地址、端口、口令三行一起复制，粘给对方即可
   （口令没填或不合规时不给复制 —— 少了口令，对方拿到文本也连不上）
4. 想开机就等着人连：在【设置…】勾选「开机后自动开始等待连接」（默认关）。
   它同时负责两件事 —— 登记开机自启、启动后自动按上次的端口与口令开始监听；
   没有已保存的口令时不会自动开始，状态栏会说明
5. 屏幕不想让人看：按 `Ctrl+Alt+F11` 一键遮挡 —— 全部屏幕变黑，对方画面定格、听不到声音、
   也失去操作权；再按一次恢复。想立刻把所有人踢掉就按 `Ctrl+Alt+F12`（停止监听，谁再连都连不上）
6. 首次监听 Windows 防火墙会弹窗，选择**允许本程序通过**；
   **当时跳过的话系统不会再提示**，之后其他电脑会连不进来。
   错过了就在「高级安全 Windows Defender 防火墙 → 入站规则」新建一条：
   选「程序」指向 `lanrdp.exe`，或者选「端口」填你上面用的那个（默认 `9000`），协议 TCP

### 控制端

1. 启动 `lanrdp.exe` → 点画面空格上的【连接远程电脑】
2. 对话框顶部会列出局域网内正在等人的电脑 —— 点一行就自动填好地址与端口
   （没发现到也能手打：被控端 `ipconfig` 查 IPv4）；再填同一口令 → 确定
3. 连接后：双击格子标题（或点悬浮条【占满】）放大单格，`Esc` 退出；
   拖放文件到画面即传输；操作权状态见悬浮条
4. 在别处 Ctrl+C 复制了文件？那一格的悬浮条上【发送文件】会亮起，点它才真的发；
   想发别的文件点按钮右侧的小三角 →【选择文件…】
   （反过来也行：在远程画面里 Ctrl+C 复制一批文件，回到本机 Ctrl+V 就落地了）
5. 被控端有 2 块以上显示器时，悬浮条上会多出【屏幕】按钮，点开可切换看哪一块
   （同一时刻只传一块，单屏被控端不会出现这个按钮）
6. 听被控端的声音：菜单【设置 → 设置…】里勾选「接收对方声音」（默认开启，会记住）

### 注意事项

- **自动发现要单独放行 UDP**：发现列表靠 UDP 广播（端口 `9001`），防火墙按协议分开放行 ——
  只放过 TCP 的话列表就是空的。这不影响手输地址连接，发现失败不是故障
- **只受理局域网内的连接**：被控端只接受来自本机所在子网的地址（以及本机回环），跨网段或
  走 VPN 进来的连接会被直接断开，服务端也不留日志。这是刻意设计，不是故障；
  要跨网段使用，得让两端在路由上看起来属于同一子网
- **两端须同一版本**：协议不兼容时表现为连接被拒或画面无响应
- **开着「最小化到托盘」时，关窗口不等于退出**：窗口进通知区域，进程仍在共享；
  要真退出先托盘右键「停止共享」，再关窗口（Win11 的托盘图标默认收在任务栏的 `^` 里）
- **流量未加密**（未做 TLS），仅适用于可信局域网，勿跨公网使用
- exe 未签名：自行编译的一般不会被拦；从他人处取得的可能触发 SmartScreen，
  点「更多信息 → 仍要运行」

## 构建

环境：Qt 6.x（MinGW 版）、MinGW-w64 编译器、CMake ≥ 3.21、Ninja。

```bash
cmake -B build -G Ninja -DCMAKE_PREFIX_PATH=<你的 Qt 安装路径>
cmake --build build
ctest --test-dir build
```

产物为 `build/lanrdp.exe`。

- **在本机运行**：把 Qt 的 `bin` 目录加入 `PATH`，或
- **拷到别的电脑**：`windeployqt build/lanrdp.exe` 把依赖 DLL 收到同目录，整个目录拷走即可
