# lanrdp — Windows 局域网远程桌面

DXGI 抓屏 + H.264 压缩 + 裸 TCP 传输的 Windows 远程桌面，Qt 6 / C++ / Win32 编写。
为**局域网**设计：低延迟、零外部服务依赖、绿色免安装。

## 功能

- **一个程序双角色**：既能当控制端连接别人，也能开监听被别人连接，可同时进行
- **多路观看**：一台控制端最多同屏连 4 台被控端（自动 2×2 网格，可单格占满）
- **多控一**：一台被控端最多接受 4 个控制端同时接入观看
- **多屏切换**：被控端有 2 块以上显示器时，悬浮条上可切换看哪一块（同一时刻只传一块）
- **操作权令牌**：同一时刻只有一个控制端能操作鼠标键盘；可申请、让出、被控端可随时收回
- **H.264 压缩**（Media Foundation 编码），也可关闭走原始帧
- **文件传输**：往画面里拖放即传；接收方自选目录，单文件上限 4 GiB
- **剪贴板双向同步**
- **声音**：控制端可听被控端的系统声音（只下行，可在设置里关）
- **断线自动重连**（带退避）+ 心跳判死
- **自适应码率**：随网络状况调整
- 深色界面；可用 `windeployqt` 打包成不依赖目标机安装 Qt 的绿色目录

## 使用

### 被控端

1. 启动 `lanrdp.exe` → 菜单【被控 → 开始监听…】（`Ctrl+1`）
2. 填端口（如 `9000`）、口令（至少 6 位、不含空格，仅英文数字符号）→ 确定
3. 首次监听 Windows 防火墙会弹窗，勾选「专用网络」；
   **当时跳过的话系统不会再提示**，之后其他电脑会连不进来

### 控制端

1. 启动 `lanrdp.exe` → 点画面空格上的【连接远程电脑】
2. 填被控端 IP（在被控端 `ipconfig` 查看 IPv4）、端口、同一口令 → 确定
3. 连接后：双击格子标题（或点悬浮条【占满】）放大单格，`Esc` 退出；
   拖放文件到画面即传输；操作权状态见悬浮条

### 注意事项

- **两端须同一版本**：协议不兼容时表现为连接被拒或画面无响应
- **流量未加密**（未做 TLS），仅适用于可信局域网，勿跨公网使用
- exe 未签名：自行编译的一般不会被拦；从他人处取得的可能触发 SmartScreen，
  点「更多信息 → 仍要运行」

## 构建

环境：Qt 6.x（MinGW 版）、MinGW-w64 编译器、CMake ≥ 3.21、Ninja。

```bash
cmake -B build -G Ninja -DCMAKE_PREFIX_PATH=<你的 Qt 安装路径>
cmake --build build
ctest --test-dir build
```

产物为 `build/lanrdp.exe`。

- **在本机运行**：把 Qt 的 `bin` 目录加入 `PATH`，或
- **拷到别的电脑**：`windeployqt build/lanrdp.exe` 把依赖 DLL 收到同目录，整个目录拷走即可
